# OmniWM (Raycast / tinycast extension)

A tiny extension that exposes your [OmniWM](https://github.com/) window-manager actions in a
command palette. Type to narrow, hit **Enter** to run — each action shells out to `omniwmctl` on
your machine, so it works in **tinycast** (which runs real Raycast extensions) and in Raycast.

## Commands

- **One command per action** — every OmniWM action (focus, move & resize, span sizing, windows,
  monitors, workspace next/prev, layout & view toggles, scratchpads) is its own palette command.
  Type to filter (e.g. `omniwm focus`), select, **Enter** runs it via `omniwmctl command …`.
- **Switch to Workspace N** — direct jumps to a numbered workspace (`switch-to-workspace-1…9`).
- **Workspaces** — live list of your workspaces (queried from `omniwmctl`). In tinycast this is a
  read-only view; in Raycast each row can *switch to* or *move the focused window* to it.
- **Actions** — a grouped browse menu of all actions. Read-only in tinycast (see note below).

## tinycast compatibility

tinycast renders a Raycast `List`, but its host **never dispatches a list item's `onAction` on
Enter** (and it rejects `noOutput` shell commands — every command needs a built JS bundle, and it
does not run plain-UI commands on Enter). The only model tinycast executes on Enter is a command
that renders a recognized UI (List / Detail / Form / Grid) whose `useEffect` does the work — the
same shape as the working **Workspaces** command. So each action here is a one-item `List` whose
`useEffect` fires `omniwmctl command …`; select + Enter runs it (the palette shows `command sent`;
dismiss with Esc). In **Raycast** the `Actions`/`Workspaces` lists are fully interactive
(onEnter fires the item's action).

## Requirements

- OmniWM running with `omniwmctl` on disk (default: `/opt/homebrew/bin/omniwmctl`).
- Node.js (used to build/run the extension).

## Run in Raycast (dev mode)

```sh
npm install
npm run dev        # `ray dev` — the extension appears in Raycast's palette live
```

## Run in tinycast

tinycast installs source Raycast extensions by running the build on your Mac (needs Node). Add this
repo to tinycast's extension list (from its URL / GitHub), or build here and import:

```sh
npm install
npm run build      # `ray build` → produces build/ that tinycast can import
```

## Extend

The per-action commands are generated by **`generate-commands.py`**: it reads the `ACTIONS` table
in that file, writes a `src/<name>.tsx` per action, builds `dist/<name>.js`, rewrites
`package.json`, and deploys into tinycast's install dir. To add an action, append a row
`(slug, title, args, keywords)` to `ACTIONS` (where `args` is the argv after `omniwmctl`) and
re-run it. The full surface is `omniwmctl --help`. The browse/list commands live in
`src/actions.tsx` + `src/workspaces.tsx` (helpers in `src/lib/omniwm.ts`).

## Notes

- Read-only queries (`omniwmctl query …`) are safe; window-mutating commands affect your live
  layout, so they run only when you explicitly pick + Enter.
- Some subcommands take an argument that OmniWM interprets in a specific unit (e.g. span sizes); if
  an entry feels off, check `omniwmctl --help` and adjust the `args`.
